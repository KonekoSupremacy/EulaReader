<h1 align="center">Eula Reader</h1>

<p align="center">
  A light novel reader for Android, built on <a href="https://github.com/lnreader/lnreader">LNReader</a>.
</p>

## Download

Grab the APK from the [latest release](https://github.com/KonekoSupremacy/EulaReader/releases/latest).

- **arm64-v8a** fits almost every phone from the last several years
- **armeabi-v7a** for older 32 bit phones
- **x86_64** for emulators and Chromebooks

The app checks this page for updates and tells you when a new version is out.

## Extensions

Sources come from [EulaReader_Extensions](https://github.com/KonekoSupremacy/EulaReader_Extensions), which the app adds on first launch. NovelFire, NovelBin, Scribble Hub and Chikari (LightNovelPub) are all in there.

## Features on top of LNReader

- tag filter in the library, include or exclude tags with suggestions and counts
- tap a genre on a novel to filter your library by it
- merge duplicate tags in Settings, Tags
- 5 star ratings, search the library with `rating>=4`
- Cloudflare protected sites load through a hidden WebView
- newest chapter on top, Chapter 1 at the bottom
- LNReader backups restore as is
